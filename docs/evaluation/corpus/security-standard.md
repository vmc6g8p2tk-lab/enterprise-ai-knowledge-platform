# Security standard

## Multi-factor authentication
All staff must enable multi-factor authentication on the corporate identity account. Hardware security keys are preferred for privileged administrators. Recovery codes belong in the approved password manager, never in a shared chat room. The service desk can reset a lost factor only after an identity check. This rule covers corporate sign-in and does not specify personal device passwords.

## Access review
Application owners review production access every 90 days. They remove unneeded roles and record the review ticket in the access register. Emergency access expires after 24 hours unless a security lead approves an extension. The access register is the evidence for auditors. A review is required even if no role changed during the previous quarter.

## Incident reporting
A suspected security incident must be reported to the security duty channel within 30 minutes of discovery. The first report includes the time, affected service and observed symptom; it should avoid copying customer secrets. The security lead assigns severity and coordinates containment. Staff should preserve relevant evidence instead of deleting suspicious files.

## Data classification
Documents containing customer identifiers are classified Confidential. Confidential files may be shared only through the approved encrypted workspace with authorized recipients. Public materials can be posted externally after the owner approves them. A classification label follows the content when it is copied into a new document. The standard does not set a retention period for recordings.
